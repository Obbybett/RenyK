# TenantConnect Kenya

TenantConnect Kenya is a modern web application designed to simplify rent management and enhance communication between landlords and tenants. This platform provides a user-friendly interface for managing rent payments, maintenance requests, and direct communication, making it easier for both parties to stay connected and informed.

## Features

- **Tenant Dashboard**: View rent balance, payment history, and maintenance requests.
- **Rent Management**: Easily manage rent payments and view history.
- **Communication System**: Direct chat feature for landlords and tenants.
- **Secure Payments**: Handle rent payments via M-Pesa or card with receipt generation.
- **Real-time Notifications**: Get alerts for rent due dates, repair updates, and messages.
- **User Authentication**: Secure login and registration for tenants and landlords.
- **Profile Management**: Update and manage user profile information.

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (version 6 or higher)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/TenantConnect-Kenya.git
   ```

2. Navigate to the project directory:
   ```
   cd TenantConnect-Kenya
   ```

3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the development server, run:
```
npm start
```

The application will be available at `http://localhost:3000`.
